# UI Components

A static HTML, CSS and JavaScript component showcase by Daniela Torres Almeida.

**All component names, contacts, education, dates and testimonials are fictional demonstration content. They are not the author’s CV or real endorsements. Forms simulate interaction and send no messages.**

[Open the showcase](https://danielatorresalmeida.github.io/ui-components/)

Serve the parent directory locally with `python -m http.server 8000`, then open `/ui-components/`. The component manifest uses this repository base path. The Navbar example is `components/nav.bar.html`.

No build, lint or automated test command is configured. This is a UI learning project; it does not claim complete accessibility coverage.
